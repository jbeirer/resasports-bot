    SportBot¶

    pysportbot.SportBot ¶

    Unified interface for interacting with the booking system.

    Creating a bot sends no requests. The centres are fetched on first use, and everything else needs login().

    Parameters:

    Name Type Description Default
    log_level str | None

    The level of the logs printed to stderr, e.g. "INFO". None leaves logging to the application.

    		 'INFO'
    time_zone str

    The time zone of the centre. Slot times are in this zone, and start times without a time zone are taken to be in it.

    		 'Europe/Madrid'

    ensure_logged_in ¶

    ensure_logged_in() -> None

    Re-login with the stored credentials if the current session is no longer valid.

    Long-running programs can call this before time-critical requests, because the session may expire some time after login(). It costs one request when the session is still valid. Otherwise it logs in again with the email, password and centre of the last successful login(), which the bot keeps in memory for this purpose. A re-login keeps the activities fetched by login(), so it does not wait for the slow activities request.

    Raises:

    Type Description
    NotLoggedInError

    If login() has never succeeded.
    AuthenticationError

    If the re-login fails.
    APIError

    If fetching the activities fails, when an earlier login failed and a full login is needed.

    book_slot ¶

    book_slot(slot: Slot) -> Slot

    Book a slot found earlier, e.g. by find_slot() or daily_slots(), with a single request.

    Unlike book(), this does not look the slot up again, so it suits time-critical bookings where the slot is found ahead of time. It does not check whether the slot is full either, because its counts may be stale by now: the API decides.

    Parameters:

    Name Type Description Default
    slot Slot

    The slot to book.

    		 required

    Returns:

    Type Description

    SlotUnavailableError

    If the slot is not available.
    SlotNotBookableYetError

    If the booking window has not opened yet.
    BookingError

    If the booking fails for another reason.
    APIError

    If the response is not a valid booking response.
